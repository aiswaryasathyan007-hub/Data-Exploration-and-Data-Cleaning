# Data-Exploration-and-Data-Cleaning
Excel Data Exploration and Data Cleaning
Project Overview

This project focuses on cleaning and preparing a Product Dataset using Microsoft Excel. The dataset was analyzed and transformed to improve data quality, consistency, and readability before further analysis.

Data Cleaning Process
1. Missing Value Handling

The dataset was checked for missing values in the Price and Category columns. Missing values were handled using suitable data-cleaning techniques.

2. Correcting Inconsistent Data

Inconsistent capitalization in the Product Name column was standardized using the PROPER CASE function. Spelling errors in the Category column were corrected using Find and Replace.

3. Duplicate Removal

Duplicate records were identified and removed using Excel's Remove Duplicates feature to maintain data accuracy.

4. Data Transformation

The Product ID was separated into Manufacturing Date and Country Code. The Brand Name and Product Name were combined into a new column called Product Brand.

5. Number and Date Formatting

The Price column was formatted using Currency format, while the Manufacturing Date was formatted as DD-MM-YYYY.

6. Conditional Formatting

Data Bars were applied to the Price column to visualize price differences. The Electronics category was highlighted using Conditional Formatting.
